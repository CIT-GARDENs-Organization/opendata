# 軌道上画像の撮影時刻と撮影条件

本文書は，`data/downlink/<衛星>/images.csv` に付与した撮影時刻と撮影条件の導出方法を示す．収録画像379点は，内容のハッシュを用いて運用記録の原本と照合した．内部文書，元ファイルの場所，コマンド列は公開しない．

## 要約

撮影条件は号機ごとに次のとおりである．撮影時刻の範囲は378点に，露出設定は379点に付与した．

| 号機 | 画像数 | 露出の指定方法 | ISO感度 | シャッター速度 |
|---|---:|---|---|---|
| KASHIWA | 104 | 3種類のプリセット | 一部は100，ほかはオートまたは不明 | 一部は1 ms，ほかはオートまたは不明 |
| SAKURA | 96 | カメラの自動露出 | オート | オート |
| YOMOGI | 121 | カメラの自動露出または既定値 | オートまたは既定値 | オートまたは既定値 |
| BOTAN | 58 | コマンドで指定 | 100，800，1600 | 0.5，1，125，2000 ms |

撮影時刻は，衛星内イベントログがあれば衛星時計から求めた．それ以外は，地上局の送信時刻または可視パス時刻に予約時間を加えた．時刻幅はKASHIWAとYOMOGIで2–5分，SAKURAで3–10分，BOTANで9–18分である．

ファイル名と `date` 列は，`capture_start` の撮影日時に統一した．時刻は日本標準時（JST）である．ダウンリンクまたは復元の日付は `downlink_date` 列に残した．

## 公開列

撮影条件に関する公開列は次のとおりである．各画像の寸法，輝度，状態，ハッシュも同じCSVに収録した．

| 列 | 内容 |
|---|---|
| `capture_start`，`capture_end` | 撮影時刻の範囲．連写と時刻の不確かさを含む |
| `downlink_date` | ダウンリンクまたは復元の日付 |
| `time_basis` | 衛星時計，地上局時刻，または可視パス時刻のいずれを用いたか |
| `iso`，`shutter` | ISO感度とシャッター速度．不明な値は空欄とする |
| `exposure_mode` | 手動，自動，プリセット，またはカメラの既定値 |
| `capture_confidence` | 対応付けの確度．`high`，`medium`，`low` の3段階 |

## 導出方法

撮影時刻と条件は，次の順序で求めた．公開CSVには，この手順から得た結果だけを収録する．

1. 画像のSHA-256を原本と照合し，同一内容であることを確認した．
2. 画像を撮影単位へまとめ，衛星内ログまたは地上局側の時刻へ対応付けた．
3. 予約時間と連写時間を加え，`capture_start` と `capture_end` を求めた．
4. 利用できる記録から露出方式，ISO感度，シャッター速度を読み取った．
5. 直接確認できない場合は時刻幅を広げ，確度を下げた．

## 号機ごとの結果

KASHIWAは，日中，夜間，ISS撮影の3種類に分かれる．撮影は2024年4月24日から7月29日までに行われた．104点のうち1点は撮影時刻を特定できない．

SAKURAは全96点が自動露出である．衛星時計の進み方を地上局の確認時刻で補正し，2024年8月30日から11月18日までの撮影へ対応付けた．

YOMOGIは全121点が自動露出またはカメラの既定値である．復元画像には同じ元画像から切り出した断片が含まれる．主な元画像は，2024年12月12日05:37–05:40 JSTと2025年1月26日15:52–16:03 JSTに撮影された．

BOTANは，ISO感度とシャッター速度を指定した画像を含む．撮影は2025年10月11日から2026年2月2日までに行われた．地上局ログにコマンドごとの秒時刻がない期間は，可視パスの幅を不確かさに含めた．

## 制約

- 自動露出で実際に選ばれた感度とシャッター速度は，画像とHKから確認できない．
- 送信時刻だけを用いた画像は，予約時間と可視パスの不確かさを含む．
- 復元画像のファイル作成日時は撮影日時と一致しない．
- `capture_confidence` が `low` の画像は，別の撮影へ対応する可能性がある．
