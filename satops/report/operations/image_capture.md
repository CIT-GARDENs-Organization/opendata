# 軌道上画像の撮影時刻と撮影条件

本文書は，[images.csv](images.csv) に付与した撮影時刻と撮影条件の列について，導出方法と号機ごとの結果を示す．収録画像379点はすべて運用記録の原本とSHA-256で一致し，撮影コマンドに対応付けた．撮影時刻の範囲は378点に，露出設定は379点に付与した．

## 要約

撮影条件は号機ごとに次のとおりである．

| 号機 | 画像数 | 露出の指定方法 | ISO感度 | シャッター速度 |
|---|---:|---|---|---|
| KASHIWA | 104 | 3種類のプリセット | ISSモード4点は100，SKRモード23点はオート，日中・夜間77点は不明 | 同左（ISSモードは1 ms） |
| SAKURA | 96 | カメラのオート露出のみ | オート | オート |
| YOMOGI | 121 | コマンドで指定可能だが全撮影でAUTO | オート（簡易撮影22点はカメラ既定値） | オート |
| BOTAN | 58 | コマンドで指定 | 100が38点，800が4点，1600が16点 | 0.5 msが42点，1 msが5点，125 msが2点，2000 msが9点 |

撮影時刻は，衛星内イベントログ（SATLOG）があれば衛星時計から，なければ地上局の送信時刻または可視パス時刻に予約タイマを加えて求めた．幅はKASHIWAとYOMOGIで2〜5分，SAKURAで3〜10分，BOTANで9〜18分である．

ファイル名と `date` 列は `capture_start` の撮影日時（JST，分まで）に統一した．ダウンリンク・復元日は `downlink_date` 列に残した．

## 列の定義

追加した列は次のとおりである．時刻はすべて日本標準時（JST，UTC+9）のISO 8601形式で，`+09:00` を付けて示す．

| 列 | 内容 |
|---|---|
| `capture_start`，`capture_end` | 撮影が行われた時刻の範囲．連写の全コマと時刻の不確かさを含む |
| `downlink_date` | 元のファイル名が示すダウンリンク・復元日．旧 `date` 列の値 |
| `time_basis` | 時刻の根拠．`satlog` は衛星内イベントログ，`uplink+timer` は地上局送信時刻と予約タイマ，`pass+timer` はパスのAOS–LOSと予約タイマ．`derived:` は切り出し画像や合成画像で，元画像の撮影時刻を示す．`unresolved` は未解決 |
| `iso` | ISO感度．`auto` はカメラの自動露出，`default` はコマンドに露出パラメータがなくカメラ既定値，空欄は不明 |
| `shutter` | シャッター速度．記法は `iso` と同じ |
| `exposure_mode` | `manual` はコマンドで数値指定，`auto` は自動露出，`preset-day`・`preset-night` はKASHIWAの日中・夜間プリセット，`default` はカメラ既定値 |
| `resolution_cmd` | コマンドで指定した出力サイズと撮像モード |
| `other_settings` | 送信したコマンドのバイト列，JPEG品質，枚数，撮影間隔，露出補正，グループ番号など |
| `capture_confidence` | `high` は衛星内ログか送信ログで撮影を直接確認，`medium` はコマンドとパス時刻からの推定，`low` はファイル名や状況からの推定 |
| `capture_source` | 根拠にした運用記録のファイル名 |
| `capture_notes` | 対応付けの補足．別候補の撮影がある場合はここに示す |

## 導出方法

導出は次の順序で行った．

1. 収録画像のSHA-256を運用記録フォルダの原本と照合し，原本のファイル名からグループ番号，コマ番号，ダウンリンク日を得た．379点すべてが一致した．
2. 各号機のコマンド生成シート，テレコマリスト，運用ハンドブックからカメラコマンドのバイト配置を復元した．
3. 運用スケジュール，運用日報，地上局モニタログから実際に送信したカメラコマンドとその時刻を集めた．
4. 衛星内イベントログがある期間は，コマンド受信と撮影実行の記録を衛星時計からJSTへ換算した．
5. 各画像を撮影コマンドへ対応付け，コマンドのバイト列を仕様で復号して設定を得た．

対応付けの手がかりは号機ごとに異なる．KASHIWAは衛星から読み出した画像サイズの一覧と復元ファイルのサイズを照合した．SAKURAはファイル名のグループ番号を用いた．YOMOGIはサムネイル領域が最新の撮影だけを保持するため，ダウンリンク日の直前の撮影を採った．BOTANは受信パケットを再構成して画像番号とグループ番号を確認した．

## 号機ごとの結果

### KASHIWA

撮影コマンドは11バイト `4B 00 A0 D2 XX p1 … p6` である．`XX` は受信から撮影までの予約時間を分単位の16進数で示す．軌道上では3種類のパラメータを用いた．

- SKRモード `00 00 00 B0 00 A4` または `… 84`：144×108のJPEGを5枚または1枚保存する．最終バイトはJPEG品質80 %，枚数，RGB，サイズを符号化したもので，コマンド生成シートで復号した．露出のフィールドはなく，カメラの自動露出である．23点が該当する．
- ISSモード `61 6D 00 00 00 00`：80×45のサムネイルを40枚保存する．2024年6月18日の会議資料にISO 100，シャッター1 ms，露出補正−5と記録がある．4点が該当する．
- 日中プリセット `76 6D 00 00 00 00` と夜間プリセット `76 9F 01 00 00 00`：640×480のJPEGを7枚保存する．運用スケジュールでは「CAM撮影（日中）」「CAM撮影（夜間）」と呼ぶ．ビット配置を記した文書もカメラ側のソースコードも運用記録にないため，数値は不明である．日中62点，夜間15点が該当する．

撮影時刻は，地上局ソフトウェアが記録した送信時刻に予約時間を加えて求めた．衛星は分単位のタイマで実行するため，実際の撮影は開始時刻から1〜2分以内である．同じコマンドを繰り返し送った場合は，最初の送信を `capture_start`，最後の送信に連写時間を加えた時刻を `capture_end` とした．撮影は2024年4月24日から7月29日までの25回で，1点は撮影を特定できなかった．

### SAKURA

撮影コマンドはECAMが `53 00 A0 B0 XX YY 00 00 00 00 PP`，SCAMが `53 00 A0 C0 XX YY 00 00 00 SS PP` である．`XX` は予約時間，`YY` はグループ番号，`SS` は連写間隔，`PP` はJPEG品質，枚数，色，サムネイルサイズを符号化したパラメータである．太陽追尾撮影 `A0 C2` は光センサのしきい値を超えたときに撮影する．

露出を指定するフィールドはなく，成果報告会資料にも「撮影パラメータ Auto/Auto」と記されている．全96点がオート露出である．JPEG品質は80 %で固定し，枚数は5枚から8枚へ，サムネイルはECAMで240×135から960×540へ，SCAMで144×108から864×648へ段階的に大きくした．SCAMにはNDフィルタが付く．

撮影時刻はSATLOGの撮影開始・終了記録から求めた．衛星時計は放出時の起動を起点とする経過時間で，地上局の受信確認時刻と比べると1日あたり48〜58 s遅れる．そこで確認できた対応点で区分線形に補正し，時期に応じて±1〜4分の幅を持たせた．撮影は2024年8月30日から11月18日までの30回である．

### YOMOGI

撮影コマンドは `59 00 A0 <sub> <timer> <grp> <shots> <cmd7> <cmd8> <cmd9> <cmd10>` である．`sub` はAKSが `A3`，AFRが `B3` のパラメータ撮影で，`cmd7` は撮像モードとサムネイルサイズ，`cmd8` はシャッター速度と露出補正，`cmd9` はホワイトバランスと測光，`cmd10` はISO感度を示す．シャッター速度は1/2000 sから2 sまで，ISO感度は100から800まで指定できる．

しかし飛行中のパラメータ撮影はすべて `B5 04 00`，すなわちシャッターAUTO，露出補正AUTO，ホワイトバランスAUTO，スポット測光，ISO AUTOで行われた．変えたのは撮像モード，サムネイルサイズ，色だけである．簡易撮影 `A0`・`B0` には露出のフィールドがなく，22点はカメラ既定値である．

撮影時刻は，2024年12月10〜20日と2025年1月17日〜2月2日の一部にSATLOGがあり，衛星時計は放出時刻2024年12月9日20:17 JSTを起点とする経過時間である．その他の期間はパスのAOS–LOSに予約時間を加えた．サムネイル領域は最新の撮影だけを保持するため，ファイル名の日付はダウンリンク日である．切り出し画像と合成画像65点は2枚の元画像から作られた．12月〜1月の切り出しはAKSグループ3のコマ1で2024年12月12日05:37 JSTの撮影，2月〜3月の切り出しはAKSグループ5のコマ4で2025年1月26日15:52〜16:03 JSTの撮影である．

### BOTAN

撮影コマンドは `42 00 A0 B1 XX YY ZZ NN MM GG SS` である．`XX` は予約時間，`YY` はグループ番号，`ZZ` は枚数，`NN` はJPEG品質とサムネイルサイズ，`MM` はミッション種別，`GG` は撮影間隔と露出補正，`SS` はISO感度とシャッター速度を示す．`SS` の符号表は運用ハンドブックの表4.10.1.2-1にあり，ISO感度は1が100，2が800，3が1600，シャッター速度は0が0.5 ms，1が1 ms，5が125 ms，9が2000 msである．成果報告会資料の2例と一致する．

飛行中の組合せは5種類である．CORNとPUMICEの多くはISO 100・0.5 ms（38点），初回撮影はISO 1600・1 ms（5点），PUMICEの一部はISO 800・0.5 ms（4点），AURORAの夜間撮影はISO 1600・2000 ms（9点），2026年1月のCORNはISO 1600・125 ms（2点）である．撮影間隔はCORN・PUMICEが3.0〜4.0 s，AURORAが30〜40 sで，露出補正は−14から+14までの値を用いた．元画像は切り出し画像の寸法から720×480と推定され，サムネイルはそこから拡大縮小したものである．

撮影時刻は，コマンドを送信したパスのAOS–LOSに予約時間と撮影所要時間を加えて求めた．所要時間はCORNとPUMICEで4分以内，AURORAで7分以内である．地上局モニタログにコマンドごとの時刻がないため，幅はパス長の7〜11分を含む．撮影は2025年10月11日から2026年2月2日までの19回である．

## 制約

- KASHIWAの日中・夜間プリセット77点は，ISO感度とシャッター速度を数値化できない．日中プリセットはISSモードと同じバイト `6D` を含むため同じ露出の可能性があるが，推定にとどまる．
- SAKURA，YOMOGIのオート露出で実際に選ばれたシャッター速度とゲインは，画像にもテレメトリにも残っていない．
- KASHIWAとBOTANには衛星時計の撮影記録がなく，時刻の幅は送信時刻またはパス長で決まる．
- ダウンリンク元のフォルダと撮影コマンドのミッションが食い違う画像が6点あった．BOTANの `pumice_20251207T0833_1aaa9e484a`，`pumice_20251207T0833_8097e2024e`，`pumice_20260116T1550_7741382f4d`，`aurora_20251124T1253_0a6d94c501` と，YOMOGIの `aks_20241212T0536_76b852024f`，`aks_20250126T1502_e819720bed` である．撮影コマンド側のミッションへ改名し，経緯は `capture_notes` に残した．
- `capture_confidence` が `low` の11点は，復元失敗の断片，送信記録のない撮影，別ラベルの切り出し画像である．
